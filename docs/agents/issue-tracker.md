# Issue tracker: Local Markdown

Specs and tickets live in `.scratch/<feature>/`. One ticket per file under
`issues/<NN>-<slug>.md`, numbered blockers-first, with **Status** and **Blocked by**.
The authoritative offline specification is `docs/offline-till-spec.md`; the local
spec links to it rather than duplicating it. Do not create remote issues or commits
unless the owner explicitly requests them.
