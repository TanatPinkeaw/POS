# Triage labels

| Role / status | Meaning |
| --- | --- |
| needs-triage | Needs maintainer assessment |
| needs-info | Waiting for information |
| ready-for-agent | Specified and ready to implement |
| ready-for-human | Requires human action |
| wontfix | Deliberately not implemented |

Implementation tickets also record `in-progress` and `done`; blocked work lists
its prerequisite ticket numbers explicitly.
